6. Control Rules

The numeric limits for Equities incl. Commodities, Fixed Income – Bonds, Alternatives / Hedge Funds and Money Market are read from the selected Combined Daily Allocation workbook. Foreign Currencies uses the current combined non-EUR currency allocation and a 0–70% limit. Eligible Investment Universe and Concentration Limit remain PASS by default. All seven controls must PASS for an account to PASS.

Current allocation source: the latest valid Combined_Daily_Allocation_YYYYMMDD.xlsx is loaded from SpeedLab SharePoint after Microsoft sign-in. A manually selected Combined Daily Allocation overrides the automatic file for that check. ELE, ADV, ENV, JOINT and Company are included; Personal is excluded from pre-trade range checks.
