6. Control Rules

Equities incl. Commodities: 25–65%. Fixed Income – Bonds: 15–60%. Alternatives / Hedge Funds: 0–40%. Foreign Currencies: 0–70%. Money Market: 0–60%. Eligible Investment Universe: PASS. Concentration Limit: PASS. All seven controls must PASS for an account to PASS.

V1 valuation: existing securities use HSBC EOP value per unit. If EOP quantity/value is unavailable, HSBC SOP value per unit is used as a fallback. If neither is available the order is flagged UNPRICED and the affected numeric controls fail. Order settlement is assumed to occur in the order currency; therefore a security-to-cash trade does not by itself change total non-EUR exposure. Explicit FX orders can be added later.
