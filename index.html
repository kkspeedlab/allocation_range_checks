6. Control Rules

Equities incl. Commodities: 25–65%. Fixed Income – Bonds: 15–60%. Alternatives / Hedge Funds: 0–40%. Foreign Currencies: 0–70%. Money Market: 0–60%. Eligible Investment Universe: PASS. Concentration Limit: PASS. All seven controls must PASS for an account to PASS.

Current allocation source: Money Market, Fixed Income, Equities incl. Commodities and Alternatives are read from the latest available rows in the Capital_Allocations sheet of the consolidated allocation workbook. The Weight column supplies Current %, while Amount supplies consolidated EUR component values and the account total used to translate trade EUR impact into percentage-point impact. Foreign Currencies continues to use the HSBC report for now.

Valuation hierarchy: existing securities use HSBC EOP value per unit, then HSBC SOP value per unit. If HSBC cannot price the ISIN, the app calls the Yahoo Finance pricing service and converts the quote to EUR. For a completely new ISIN, Yahoo metadata is used to infer Equities/Commodities versus Fixed Income where possible; uncertain classifications remain REVIEW and prevent final PASS. Order settlement is assumed to occur in the order currency, so a security-to-cash trade does not by itself change total non-EUR exposure. Explicit FX orders can be added later.
